克莱因-戈登方程

克莱因-戈登方程是量子场论的「入门第一方程」，

克莱因-戈登方程（Klein-Gordon Equation）

1. 背景：把薛定谔方程推广到相对论

薛定谔方程来自非相对论的能量-动量关系：

E = \frac{\mathbf p^2}{2m} \;\xrightarrow{\;E \to i\hbar \frac{\partial}{\partial t},\ \mathbf p \to -i\hbar\nabla\;}\; i\hbar\frac{\partial\psi}{\partial t} = -\frac{\hbar^2}{2m}\nabla^2\psi

但它是一阶对时间、二阶对空间，时间和空间地位不对等，不符合狭义相对论的要求（洛伦兹协变）。相对论中自由粒子的能量-动量关系是：

E2=p2c2+m2c4E^2 = \mathbf p^2 c^2 + m^2 c^4 E​2​​=p​2​​c​2​​+m​2​​c​4​​

把上面的量子化替换规则代进去，就得到克莱因-戈登方程：

(1c2∂2∂t2−∇2+m2c2ℏ2)ϕ=0\left( \frac{1}{c^2}\frac{\partial^2}{\partial t^2} - \nabla^2 + \frac{m^2 c^2}{\hbar^2} \right) \phi = 0 (​c​2​​​​1​​​∂t​2​​​​∂​2​​​​−∇​2​​+​ℏ​2​​​​m​2​​c​2​​​​)ϕ=0

采用自然单位（ℏ=c=1\hbar = c = 1ℏ=c=1），并用四维协变记号 ∂μ=(∂t,∇)\partial_\mu = (\partial_t, \nabla)∂​μ​​=(∂​t​​,∇)、达朗贝尔算子 □=∂μ∂μ=∂t2−∇2\Box = \partial_\mu \partial^\mu = \partial_t^2 - \nabla^2□=∂​μ​​∂​μ​​=∂​t​2​​−∇​2​​，方程写成最简洁的形式：

\boxed{\;(\partial_\mu \partial^\mu + m^2)\,\phi = 0 \quad\Longleftrightarrow\quad (\Box + m^2)\phi = 0\;}

时间、空间都变成二阶导数，形式上完全对称，因此是洛伦兹协变的——这是它对薛定谔方程的本质改进。

2. 平面波解

设平面波解 ϕ(x,t)∼e−i(ωt−k⋅x)\phi(\mathbf x, t) \sim e^{-i(\omega t - \mathbf k \cdot \mathbf x)}ϕ(x,t)∼e​−i(ωt−k⋅x)​​，代入方程得到色散关系（自然单位）：

ω2=k2+m2⟹ω=±k2+m2\omega^2 = \mathbf k^2 + m^2 \;\Longrightarrow\; \omega = \pm\sqrt{\mathbf k^2 + m^2} ω​2​​=k​2​​+m​2​​⟹ω=±√​k​2​​+m​2​​​​​

频率有正负两支：负频率解 e+i∣ω∣te^{+i|\omega| t}e​+i∣ω∣t​​ 不能简单丢掉，因为要构成完备基。于是：

  • 正频解：ϕ(+)∼e−iωt\phi^{(+)} \sim e^{-i \omega t}ϕ​(+)​​∼e​−iωt​​，对应能量 E=+ωE = +\omegaE=+ω
  • 负频解：ϕ(−)∼e+iωt\phi^{(-)} \sim e^{+i \omega t}ϕ​(−)​​∼e​+iωt​​，对应能量 E=−ωE = -\omegaE=−ω

3. 问题：负能量与概率诠释的崩溃

如果把 ϕ\phiϕ 当成像薛定谔波函数那样「单粒子概率幅」，就会遇到两个致命问题：

(a) 概率密度可以为负。 由连续性方程构造出的「概率密度」：

ρ=iℏ2mc2(ϕ∗∂ϕ∂t−ϕ∂ϕ∗∂t)\rho = \frac{i\hbar}{2mc^2}\left( \phi^* \frac{\partial \phi}{\partial t} - \phi \frac{\partial \phi^*}{\partial t} \right) ρ=​2mc​2​​​​iℏ​​(ϕ​∗​​​∂t​​∂ϕ​​−ϕ​∂t​​∂ϕ​∗​​​​)

它不再是正定的——因为方程对时间二阶，ϕ\phiϕ 和 ∂tϕ\partial_t \phi∂​t​​ϕ 可以独立取值，ρ\rhoρ 可以取负值。负概率在物理上无法接受。

(b) 能量无下界。 负频率意味着粒子可以不断向 −∞-\infty−∞ 掉能量，体系不稳定（「向下无限跌落」）。

结论：克莱因-戈登方程不能作为单粒子波函数的运动方程——它不能描述「一个粒子在哪里、概率多大」这件事。
